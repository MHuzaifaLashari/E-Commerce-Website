CITADEL BRANDS STATIC HOMEPAGE — FIGMA ASSETS

1. Extract the ZIP file.
2. Keep index.html and the assets folder together.
3. Open index.html in Chrome or Edge.

The page uses local copies of the imagery used for the Figma Design 4 homepage.
It does not require FDM4 variables and does not rely on temporary Figma URLs.

For web hosting, upload index.html and the complete assets folder without
changing their relative folder structure.
